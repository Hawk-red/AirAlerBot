# Монитор ракетных угроз для Киева и области

Этот скрипт мгновенно (задержка < 0.5 сек) отслеживает публикации в официальном Telegram-канале Воздушных Сил ВСУ (`@kpszsu`), фильтрует сообщения по ключевым словам для Киева и Киевской области и отправляет предупреждения через вашего Telegram-бота.

---

## Шаг 1. Подготовка данных в Telegram

Для работы скрипта требуются:
1. **Telegram API ID & API Hash:**
   * Зайдите на https://my.telegram.org.
   * Войдите под своим номером телефона.
   * Перейдите в **API development tools**.
   * Создайте приложение (имя любое, например `alert_monitor`).
   * Сохраните `api_id` (число) и `api_hash` (строка).

2. **Токен Telegram-бота:**
   * Напишите боту `@BotFather` в Telegram команду `/newbot`.
   * Задайте имя боту.
   * Скопируйте токен бота (например, `123456789:ABCdef...`).

3. **Ваш Chat ID:**
   * Напишите вашему созданному боту команду `/start`.
   * Перешлите любое сообщение из этого диалога боту `@userinfobot`, чтобы узнать ваш числовой ID (например, `987654321`).

---

## Шаг 2. Установка на сервер Ubuntu

1. Создайте папку для проекта на сервере:
   ```bash
   sudo mkdir -p /opt/alert_monitor
   sudo chown -R $USER:$USER /opt/alert_monitor
   ```
2. Скопируйте все файлы из этой папки (`main.py`, `config.json`, `requirements.txt`, `alert_monitor.service`) в созданную папку `/opt/alert_monitor` на сервере.
3. Установите зависимости:
   ```bash
   cd /opt/alert_monitor
   pip3 install -r requirements.txt
   ```

---

## Шаг 3. Настройка конфигурации

Откройте файл `config.json` на сервере и заполните сохраненные ранее данные:
```json
{
    "telegram_api_id": 1234567,              // Ваш api_id (число)
    "telegram_api_hash": "ваш_api_hash",      // Ваш api_hash
    "bot_token": "ваш_токен_бота",            // Токен от @BotFather
    "chat_id": 987654321,                     // Ваш Chat ID
    "monitored_channel": "kpszsu",
    "keywords": [
        "київ", "києв", "київщ", "київськ", "київськи",
        "бровар", "борисп", "васильк", "ірпін", "обухів", "вишгород"
    ]
}
```

---

## Шаг 4. Первый запуск и авторизация (Важно!)

При первом запуске скрипт должен подключиться как ваш Telegram-аккаунт. Это требует интерактивного ввода телефона и кода подтверждения:
```bash
python3 main.py
```
1. Скрипт попросит ввести ваш номер телефона (в международном формате, например `+380...`).
2. В Telegram на вашем телефоне придет служебное сообщение с кодом подтверждения (не SMS, а сообщение от официального аккаунта Telegram). Введите его в консоль.
3. Если у вас включен двухфакторный пароль (Two-Step Verification), введите его.
4. После успешного входа в папке создастся файл сессии `alert_monitor.session`. Теперь скрипт авторизован и может работать автономно.
5. Нажмите `Ctrl+C`, чтобы остановить скрипт.

---

## Шаг 5. Настройка автозапуска (systemd)

Чтобы мониторинг работал круглосуточно в фоновом режиме:
1. Скопируйте файл службы в системную директорию:
   ```bash
   sudo cp alert_monitor.service /etc/systemd/system/
   ```
2. Откройте `/etc/systemd/system/alert_monitor.service` и убедитесь, что в поле `User` указано имя вашего пользователя на сервере (например, `ubuntu` или `root`), а пути верны:
   ```ini
   User=имя_вашего_пользователя
   WorkingDirectory=/opt/alert_monitor
   ExecStart=/usr/bin/python3 main.py
   ```
3. Обновите конфигурацию системных служб и запустите монитор:
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable alert_monitor.service
   sudo systemctl start alert_monitor.service
   ```
4. Проверьте статус работы службы:
   ```bash
   sudo systemctl status alert_monitor.service
   ```

## Тестирование и диагностика

* **Проверка отправки сообщений ботом:**
  Вы можете отправить тестовое сообщение через вашего настроенного бота:
  ```bash
  python3 main.py --test-bot
  ```
* **Проверка фильтрации ключевых слов:**
  Проверьте, срабатывает ли фильтр на нужные фразы:
  ```bash
  python3 main.py --test-filter "Увага! Крилата ракета на Київ!"
  python3 main.py --test-filter "Шахеди летять у напрямку Броварів"
  python3 main.py --test-filter "Балістика на Львів" # Совпадений быть не должно
  ```
* **Просмотр логов работы службы:**
  ```bash
  journalctl -u alert_monitor.service -f
  # Или просмотр файла логов в папке проекта:
  tail -f alert_monitor.log
  ```
